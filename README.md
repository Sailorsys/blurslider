# Blur Slider Demo

مشروع Android بسيط بلغة Kotlin لتجربة اختيار صورة والتحكم في قوة Blur بواسطة SeekBar.

## ما الذي يوضحه المشروع؟

يستخدم المشروع `ImageView` لعرض الصورة المختارة، و`SeekBar` لتغيير نصف قطر التمويه لحظيًا. عند اختيار قيمة صفر تعود الصورة إلى وضعها الطبيعي.

المشروع لا يستخدم Chaquopy أو Python أو ML Kit؛ وهو مقصود كتجربة صغيرة لفهم فصل واجهة المستخدم عن مرحلة معالجة الصور قبل إضافة العزل وخريطة العمق.

## المتطلبات

- Android Studio حديث أو بيئة Gradle حقيقية.
- Android SDK 34.
- جهاز أو محاكي Android 12 أو أحدث، لأن `RenderEffect` يحتاج API 31 أو أعلى.
